# 04. JavaScript Interview Questions

## Questions

1. Explain the JavaScript event loop.
2. Microtask queue vs macrotask queue?
3. Explain Promises and async/await.
4. What happens internally when you use `await`?
5. `Promise.all()` vs `Promise.allSettled()` vs `Promise.race()` vs `Promise.any()`?
6. Explain closures with a real-world example.
7. What is lexical scope?
8. Explain `this` in JavaScript.
9. Arrow function vs normal function.
10. Explain prototype inheritance.
11. `==` vs `===`.
12. Shallow copy vs deep copy.
13. What are JavaScript memory leaks?
14. How would you identify a memory leak in a browser application?
15. Explain debouncing vs throttling.
16. How would you optimize a JavaScript application processing millions of records?
17. What are Web Workers?
18. When would you use Web Workers in Angular?
19. Explain tree shaking.
20. What is code splitting?
21. What is lazy loading?
22. Explain ES modules.
23. CommonJS vs ES Modules.
24. What are generators and iterators?
25. Explain immutability and why it matters with Angular OnPush.

## Coding Practice

- Implement debounce without a library.
- Implement throttle without a library.
- Implement a concurrency-limited Promise executor.
- Flatten a deeply nested array.
- Implement memoization.
- Find duplicate objects by a key.
- Process a large dataset without blocking the browser.
